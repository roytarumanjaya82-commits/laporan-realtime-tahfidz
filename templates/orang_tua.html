Password Default Sistem

Semua akun orang tua baru memakai password default yang sama. Username login = nama orang tua (sesuai data siswa).

Cara Kerja

  1. Isi nama_orang_tua saat tambah siswa / upload blanko.
  2. Sistem otomatis membuat akun login (username = nama ortu).
  3. Beritahu orang tua password default: {{ default_password }}
  4. Orang tua login → lihat perkembangan anak → boleh ganti password sendiri.
  5. Jika lupa, admin bisa reset per akun di tabel di bawah.
